# 👔 HR Manager

## Overview

**Role ID**: `hr_manager`  
**Category**: Human Resources  
**Access Level**: 3 (High - Employee data)  
**License Requirement**: HRM & Payroll Addon

---

## Description

HR Manager quản lý employee lifecycle từ recruitment đến offboarding, xử lý HR policies, attendance, leave management, và performance reviews. Requires HRM & Payroll addon.

---

### 1. Recruitment & Onboarding (🤖 AI-Enhanced)
- Post job openings to multiple platforms
- Screen candidates and CVs
- Conduct interviews
- Process hiring paperwork
- Onboard new employees
- **🆕 AI-powered CV screening and matching**
- **🆕 Automated candidate scoring**
- **🆕 AI interview question suggestions**
- **🆕 Digital onboarding workflows**

### 2. Employee Management (🤖 AI-Enhanced)

- Manage contracts and renewals

- **🆕 Automated contract renewal reminders**

- Monitor attendance (auto-tracked for teachers)
- Approve/reject leave requests
- Track leave balances automatically
- Manage time-off policies
- **🆕 AI attendance pattern analysis**
- **🆕 Automated leave balance calculations**
- **🆕 Smart leave approval recommendations**

### 4. Performance Management (🤖 AI-Enhanced)

- Collect feedback from multiple sources

- **🆕 AI-powered performance insights**

- Maintain HR documentation

## User Scenarios

### Scenario 1: Hiring New Teacher

**Steps**:
1. Receive hiring request from [[Academic Manager]]
2. Create job posting:
   - Position: English Teacher
   - Requirements: BA + 2 years exp
   - Location: HN Central Branch
3. Post on recruitment channels
4. Screen applications (50 received)
5. Shortlist candidates (10)
6. Schedule interviews with Academic Manager
7. Conduct interviews (5 candidates)
8. Select candidate: Ms. Lan
9. Prepare offer letter:
   - Salary: 15M VND/month
   - Benefits: Insurance, paid leave
   - Start date: Next month
10. Process onboarding:
    - Collect documents
    - Create employee record
    - Setup system account
    - Orientation schedule
11. Add to payroll
12. Notify [[Academic Manager]]

**Expected Outcome**: New teacher onboarded successfully

---

### Scenario 2: Approving Leave Request

**Steps**:
1. Receive leave request from [[Teacher]]
   - Employee: Mr. Tran
   - Type: Annual leave
   - Dates: Sep 15-20 (5 days)
   - Reason: Family vacation
2. Check leave balance:
   - Annual leave remaining: 8 days ✓
3. Check impact:
   - Classes scheduled: 6 classes
   - Coverage available: Yes (substitute teacher)
4. Consult [[Academic Manager]] for coverage plan
5. Approve request
6. Update leave balance: 8 → 3 days
7. Notify Mr. Tran
8. Notify Academic Manager to arrange substitute
9. Log in HR system

**Expected Outcome**: Leave approved, operations planned

---

### Scenario 3: Performance Review

**Steps**:
1. Launch quarterly review cycle
2. Send review forms to all managers
3. Managers complete reviews for direct reports
4. HR reviews for consistency
5. Schedule 1-on-1 meetings
6. During meeting:
   - Discuss achievements
   - Address challenges
   - Set goals for next quarter
   - Document action items
7. Employee signs review
8. File in HR records
9. Track development goals

**Expected Outcome**: Reviews completed, goals set
