## Executive Summary

**AI-powered, self-hosted Learning Management System** cho trung tâm đào tạo tư nhân tại Vietnam, hỗ trợ **đa ngành**, **đa chi nhánh**, và **online/offline/hybrid learning**. Hệ thống cài đặt trên server riêng của khách hàng, kích hoạt bằng **license key offline**, đảm bảo **data residency** và bảo mật thông tin.

- 🤖 **AI-First**: AI teaching assistant, auto-grading, personalized learning paths
- 🎥 **Hybrid Learning**: Online, offline, and blended class support with seamless switching
- 🌐 **Multi-Industry**: Language, IT, Design, Cooking, and 10+ domains with specialized workflows

- 💬 **Communication Hub**: Integrated messaging for staff, students, teachers, and parents

- ✅ **On-premise**: Customer owns their data, meets Vietnam data residency requirements

- ✅ **Modular**: Base system + paid addons for flexibility

### Current Pain Points

**Educational institutions in Vietnam face**:
- ❌ Spreadsheet chaos for student management
- ❌ Manual processes for enrollment, attendance, grading
- ❌ Cannot support online/hybrid learning effectively
- ❌ No AI-powered teaching assistance or auto-grading
- ❌ Manual grading takes too much teacher time
- ❌ No personalized learning paths for students
- ❌ Poor communication between school, teachers, parents
- ❌ Limited to single industry teaching methods
- ❌ Cannot manage both physical and virtual classrooms
- ❌ No digital library or interactive content platform
- ❌ Data scattered across multiple tools (Google Sheets, WhatsApp, email)

**Why existing solutions don't work**:
- **Cloud SaaS**: Data residency concerns, ongoing subscription costs, internet dependency
- **International LMS** (Moodle, Canvas): Overkill complexity, not localized, expensive hosting
- **Local competitors**: Single-branch only, no AI features, outdated UX, no hybrid learning

## Technical Architecture

### Tech Stack

**Frontend**:
```yaml
Framework: React 19
UI Library: Ant Design Pro 6.x
Build Tool: Vite 5.x
State: Zustand (lightweight)
Data Fetching: TanStack Query
Forms: React Hook Form + Zod
i18n: react-i18next (Vietnamese + English)
PWA: Workbox for service workers
```

**Backend**:
```yaml
Runtime: Node.js 20 LTS
Framework: NestJS 10.x
ORM: TypeORM
Database: PostgreSQL 15+ with pgvector
Cache/Queue: Redis 7+ (BullMQ for jobs)
Validation: class-validator
API Docs: OpenAPI 3.0 (Swagger)
Real-time: Socket.IO (chat, notifications)
Media: FFmpeg (video processing)
```

**AI/ML Stack**:
```yaml
LLM APIs:
  - OpenAI (GPT-4 for grading, content generation)
  - Anthropic Claude (alternative)
  - OpenAI Whisper (speech-to-text)
Vector DB: pgvector (PostgreSQL extension)
ML Models: TensorFlow.js (custom models)
Semantic Search: Embeddings + vector search
```

**Deployment**:
```yaml
Target OS: Debian 12 / Ubuntu 22.04 LTS
Web Server: Nginx (reverse proxy)
Process Manager: systemd
Package Format: .deb (dpkg/apt)
Storage: Local filesystem or S3-compatible (Minio)
Monitoring: Journalctl logs + optional Prometheus
Backup: Automated daily PostgreSQL dumps
```

**Why On-Premise?**:
- Customer requirement for data control
- Meets Vietnam data residency laws
- No recurring cloud costs
- Better performance on local network
- Simpler for small IT teams to manage

## Risk Mitigation

### Technical Risks
| Risk | Mitigation |
|------|------------|
| AI API costs too high | Offer tiered AI usage, cache responses, use cheaper models for simple tasks |
| Video storage expensive | Configurable retention, compression, optional S3/Minio |
| Performance with 5000+ students | Database optimization, Redis caching, horizontal scaling ready |
| On-premise deployment issues | Comprehensive docs, remote support, optional managed hosting |

### Business Risks
| Risk | Mitigation |
|------|------------|
| Low adoption | Pilot with 2 customers, iterate, strong marketing |
| Price resistance | Flexible pricing, bundle discounts, ROI calculator |
| Competition | Focus on AI differentiation, Vietnamese UX, superior support |
| Churn | Strong onboarding, regular training, feature updates |

### Market Risks
| Risk | Mitigation |
|------|------------|
| Cloud SaaS preference | Emphasize data ownership, cost savings, compliance |
